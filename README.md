# Skypro Wallet

Веб-приложение для учета и анализа личных расходов с интуитивным интерфейсом и визуализацией данных.

## Описание

Skypro Wallet — это современное React-приложение для управления личными финансами. Пользователи могут добавлять расходы, отслеживать их по категориям и анализировать свои траты с помощью интерактивного календаря и диаграмм.

## Основные возможности

### Аутентификация

- **Вход в систему** — форма входа с валидацией email и пароля
- **Регистрация** — создание нового аккаунта с проверкой данных
- Валидация полей в реальном времени с визуальной обратной связью
- Отображение ошибок валидации с помощью звездочек и цветовых индикаторов

### Управление расходами

- **Добавление расходов** с указанием:
  - Описания расхода
  - Категории (Еда, Транспорт, Жилье, Развлечения, Образование, Другое)
  - Даты
  - Суммы
- **Таблица расходов** с отображением всех записей
- **Удаление расходов** одним кликом
- Валидация всех полей формы перед добавлением

### Анализ расходов

- **Интерактивный календарь** для выбора периода анализа
  - Выбор диапазона дат (два клика)
  - Прокрутка календаря с фиксированными днями недели
  - Визуальное выделение выбранного периода
- **Диаграмма расходов по категориям**:
  - Столбчатая диаграмма с цветовой кодировкой
  - Отображение суммы по каждой категории
  - Автоматический расчет пропорций
- **Общая статистика** за выбранный период

## Технологии

- **React 18.2.0** — библиотека для создания пользовательского интерфейса
- **Vite 5.0.8** — инструмент сборки и разработки
- **CSS3** — стилизация компонентов
- **JavaScript (ES6+)** — логика приложения

## Установка и запуск

### Предварительные требования

- Node.js (версия 16 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Просмотр продакшен-сборки

```bash
npm run preview
```

## Особенности реализации

### Валидация форм

- Валидация в реальном времени при вводе данных
- Визуальная обратная связь (зеленый цвет для валидных полей, красный для невалидных)
- Отображение звездочек (\*) рядом с полями, содержащими ошибки
- Блокировка кнопки отправки при наличии ошибок

### Управление состоянием

- Использование React Hooks (useState, useMemo, useRef)
- Поднятие состояния расходов на уровень App для совместного использования
- Мемоизация вычислений для оптимизации производительности

### Обработка данных

- Защита от edge cases (пустые массивы, null значения)
- Валидация парсинга дат с обработкой ошибок
- Форматирование сумм в формат с пробелами и символом рубля
- Нормализация дат для корректного сравнения

### UI/UX

- Адаптивный дизайн согласно макету Figma
- Интерактивные элементы с hover-эффектами
- Прокручиваемый календарь с фиксированными заголовками дней недели
- Визуальное выделение выбранных дат и периодов

## Безопасность и валидация

- Валидация email с помощью регулярных выражений
- Проверка минимальной длины пароля (6 символов)
- Валидация числовых значений (сумма должна быть положительным числом)
- Проверка обязательных полей перед отправкой формы

## Категории расходов

Приложение поддерживает следующие категории:

- **Еда** — продукты питания, рестораны, кафе
- **Транспорт** — такси, бензин, общественный транспорт
- **Жилье** — аренда, коммунальные услуги
- **Развлечения** — кино, игры, хобби
- **Образование** — курсы, книги, обучение
- **Другое** — прочие расходы
